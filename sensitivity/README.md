# Post hoc sensitivity analysis

`outputs/tables/table_s13.csv` contains aggregate results after excluding 19 main-study responses matched to Prolific's post hoc LLM-check export. The remaining sample was N = 967.

The public files omit participant identifiers and the row-level classification. Reproducing this exclusion requires authorized access to the original platform export and study records. The full-sample analyses use the public data.
